# Privacy Policy

Clawd does not collect telemetry, analytics, advertising identifiers, or personal data.

- AI requests are sent only to the API endpoint configured by the user.
- API keys are stored locally in `config.json` or `.env`. They are not sent to the project maintainers and are not bundled with the application.
- Chat history is kept in the local configuration file so the pet can continue a conversation. It is not uploaded anywhere except to the endpoint selected by the user as part of the active request.
- The application does not contact any project-operated server.
- Third-party API providers and Ollama have their own privacy policies.

To report a privacy issue, open an issue at:

https://github.com/bmarcnhii1-max/clawd-botik/issues
