# Clawd — пиксельный питомец для рабочего стола

Маленький пиксельный питомец для Windows. Живёт на рабочем столе, гуляет, реагирует на клики и перетаскивание, спит, видит сны и умеет общаться через OpenAI-совместимый API или локальную модель Ollama.

## Возможности

- Прозрачное окно поверх других окон, пиксельная анимация.
- Перетаскивание, бросок, поглаживание и клики.
- Гравитация, самостоятельная ходьба, сон и мысли во сне.
- Шесть палитр и три размера.
- Интерфейс на русском, украинском и английском.
- Чат с ИИ и краткая история диалога.
- Облачный режим для любого OpenAI-совместимого API.
- Локальный режим через Ollama; режим размышлений отключён для быстрых ответов.
- Меню в трее и защита от запуска второй копии.
- Сборка `.exe` для Windows (без автозапуска).

## Требования

- Windows 10/11 или Linux (рекомендуется X11; Wayland через XWayland).
- Python 3.10+ (проверено на Python 3.14).
- Ollama — только для локальной модели.

## Быстрый запуск

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

Либо запустите `run.bat` после установки зависимостей.

## Linux

Python-версия работает на Linux. Лучше всего проверена на X11; на Wayland обычно работает через XWayland. Для иконки в трее на GNOME может понадобиться расширение AppIndicator.

```bash
sudo apt update
sudo apt install -y python3-venv python3-pip libgl1 libegl1 libxcb-cursor0 libxkbcommon-x11-0 libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-render-util0
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
chmod +x run.sh
./run.sh
```

Если на Wayland не работают прозрачность, позиционирование или иконка в трее, принудительно включите X11:

```bash
QT_QPA_PLATFORM=xcb ./run.sh
```

`build.bat` и `setup_local_model.ps1` предназначены для Windows. На Linux запускайте из исходников, а Ollama устанавливайте официальным установщиком; `config.py` и `.env` работают так же.

## Настройка ИИ

Clawd работает и без ИИ, но для чата нужен облачный endpoint или локальная модель Ollama.

### Облако / OpenAI-совместимый API

1. Откройте меню в трее.
2. Выберите **Настройки ИИ…**.
3. Укажите адрес API, ключ и название модели.
4. Сохраните и задайте вопрос.

Можно также скопировать `config.example.json` в `config.json` и отредактировать его. `config.json` исключён из Git.

### Переменные окружения

Скопируйте `.env.example` в `.env` и заполните свои значения:

```dotenv
CLAWD_AI_BASE_URL=https://api.example.com/v1
CLAWD_AI_MODEL=model-name
CLAWD_AI_KEY=your-key
```

`.env` исключён из Git. Переменные окружения имеют приоритет над значениями из `config.json`.

### Локальная модель Ollama

1. Установите и запустите Ollama.
2. Запустите вспомогательный скрипт:

```powershell
powershell -ExecutionPolicy Bypass -File .\setup_local_model.ps1
```

Он скачает текстовую Gemma 4 E2B Q4_K_M GGUF (около 3.1 ГБ) в `models/` и создаст модель Ollama `gemma4-e2b-local`.

Как вариант, используйте официальную модель:

```powershell
ollama pull gemma4:e2b
```

После этого укажите `ai_local_model` как `gemma4:e2b` в `config.json`.

Затем выберите в трее **Модель ИИ → Локально — Gemma 4 E2B**.

## Управление

- Левый клик: погладить или ткнуть.
- Перетаскивание: переместить питомца; бросьте, чтобы он полетел.
- Встряхивание при перетаскивании: переключение русского → украинского → английского.
- Правый клик: меню.
- Двойной клик по иконке в трее: показать или скрыть питомца.

Питомец засыпает через три минуты без взаимодействия и может показывать мысли во сне.

## Сборка `.exe`

```powershell
pip install -r requirements-dev.txt
build.bat
```

Готовый файл: `dist\Clawd.exe`. Модели, `config.json`, `.env` и артефакты сборки в executable не попадают.

Для быстрой локальной проверки используйте `build.bat fast`: кэш PyInstaller сохраняется, а приложение собирается в папку `dist\Clawd\Clawd.exe`, без повторной упаковки onefile.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `main.py` | Точка входа, трей, защита от второго запуска |
| `pet_window.py` | Поведение, анимация, сон, перетаскивание и встряхивание |
| `sprite.py` | Пиксельные кадры и палитры |
| `bubble.py` | Облачко сообщений и снов |
| `dialogs.py` | Чат и диалоги настроек |
| `ai_client.py` | HTTP-клиент для OpenAI-совместимого API |
| `config.py` | Конфигурация, значения по умолчанию, `.env` |
| `i18n.py` | Переводы интерфейса |
| `phrases.py` | Фразы, сны и характер ИИ |
| `setup_local_model.ps1` | Опциональная установка локальной Gemma |
| `run.sh` | Запуск на Linux |
| `build.bat` | Сборка через PyInstaller |

## Безопасность

- Не коммитьте `config.json`, `.env`, API-ключи, скачанные модели и результаты сборки.
- Если ключ когда-либо попал в репозиторий или был кому-то отправлен, отзовите его и создайте новый.
- `.env.bait` — нерабочая приманка для автоматических сканеров. Приложение её не читает.
- Приложение обращается только к указанному вами API или локальному Ollama. Телеметрии нет.
