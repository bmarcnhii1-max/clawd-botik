# Clawd — Настольный AI-питомец

Очаровательный пиксельный питомец для вашего рабочего стола Windows или Linux. Наблюдайте, как он гуляет, спит и видит сны. Взаимодействуйте с ним через клики и перетаскивание. Общайтесь с ним через любой OpenAI-совместимый API или локальную модель Ollama.

## Возможности

- Прозрачный пиксельный питомец, всегда поверх окон, с плавной анимацией
- Полная поддержка взаимодействия: перетаскивание, броски, поглаживание и касания
- Симуляция физики: гравитация, самостоятельная ходьба, сон и облачка снов
- Шесть цветовых палитр и три размера на выбор
- Многоязычный интерфейс: английский, русский, украинский
- AI-чат с историей разговоров
- Облачный AI-режим: работает с любым OpenAI-совместимым API
- Локальный AI-режим: приватная работа через Ollama (быстрые ответы без расширенного мышления)
- Интеграция с системным треем и защита от повторного запуска
- Опциональный Windows-исполняемый файл (без автозапуска, портативный)

## Требования

- **ОС**: Windows 10/11 или Linux (рекомендуется X11; Wayland работает через XWayland)
- **Python**: 3.10 или новее (проверено до 3.14)
- **Ollama**: необязательно, только если хотите использовать локальные AI-модели

## Быстрый старт (Windows)

```powershell
# Создайте и активируйте виртуальное окружение
python -m venv .venv
.venv\Scripts\Activate.ps1

# Установите зависимости
pip install -r requirements.txt

# Запустите Clawd
python main.py
```

**Альтернатива:** После установки зависимостей просто запустите:
```powershell
run.bat
```

## Быстрый старт (Linux)

X11 полностью протестирован; Wayland работает через XWayland (на GNOME может потребоваться расширение AppIndicator).

### Установка зависимостей

```bash
sudo apt update
sudo apt install -y python3-venv python3-pip libgl1 libegl1 libxcb-cursor0 \
  libxkbcommon-x11-0 libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-render-util0
```

### Запуск Clawd

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
chmod +x run.sh
./run.sh
```

### Устранение проблем на Wayland

Если прозрачность, позиционирование окна или иконка трея ведут себя странно:
```bash
QT_QPA_PLATFORM=xcb ./run.sh
```

**Примечание:** `build.bat` и `setup_local_model.ps1` работают только на Windows. На Linux установите Ollama отдельно через официальный установщик; `config.py` и `.env` работают одинаково на всех платформах.

## Настройка AI

Clawd отлично работает без AI (он будет гулять, спать и видеть сны). Для чата нужен либо облачный API, либо локальная модель Ollama.

### Вариант 1: Облачный API (OpenAI-совместимый)

**Через интерфейс:**
1. Кликните правой кнопкой на питомце → **AI settings…**
2. Введите URL API, ключ API и название модели
3. Сохраните и начинайте общение

**Через файл конфигурации:**
1. Скопируйте `config.example.json` в `config.json`
2. Отредактируйте настройки AI
3. Перезапустите Clawd

(`config.json` игнорируется Git-ом)

### Вариант 2: Переменные окружения

Создайте или отредактируйте `.env`:

```dotenv
CLAWD_AI_BASE_URL=https://api.example.com/v1
CLAWD_AI_MODEL=model-name
CLAWD_AI_KEY=your-api-key
```

Переменные окружения имеют более высокий приоритет, чем значения из `config.json`. (`.env` игнорируется Git-ом)

### Вариант 3: Локальная модель Ollama

**Автоматическая настройка (Windows):**
```powershell
powershell -ExecutionPolicy Bypass -File .\setup_local_model.ps1
```
Скрипт загрузит Gemma 4 E2B (~3,1 ГБ) и настроит её автоматически.

**Ручная настройка (все платформы):**
```bash
ollama pull gemma4:e2b
```
Затем установите `ai_local_model` в значение `gemma4:e2b` в `config.json` и выберите **AI model → Local — Gemma 4 E2B** в меню трея.

## Управление

| Действие | Эффект |
|----------|--------|
| **Левый клик** | Коснуться или погладить питомца |
| **Тройной левый клик** | Открыть чат с ИИ |
| **Перетаскивание** | Перемещать питомца по экрану |
| **Перетащить + бросить** | Подбросить питомца, чтобы он полетел |
| **Перетащить + встряхнуть** | Переключать языки: английский → русский → украинский |
| **Правый клик** | Открыть контекстное меню |
| **Двойной клик по иконке в трее** | Переключить видимость питомца |

**Поведение:** Питомец автоматически засыпает после 3 минут бездействия и может показывать облачка снов во время сна.

## Построение Windows-исполняемого файла

### Полная сборка

```powershell
pip install -r requirements-dev.txt
build.bat
```

Результат: `dist\Clawd.exe` (самостоятельный исполняемый файл)

**Примечание:** Модели, `config.json`, `.env` и артефакты сборки *не* упаковываются внутрь — держите их в той же папке, что и исполняемый файл.

### Быстрая сборка (для разработки)

```powershell
build.bat fast
```

Повторно использует кеш PyInstaller и строит версию в папке (`dist\Clawd\Clawd.exe`) для более быстрых итераций.

## Структура проекта

| Файл | Назначение |
|------|------------|
| `main.py` | Точка входа, меню системного трея, защита от повторного запуска |
| `pet_window.py` | Поведение питомца, анимации, физика, обработка перетаскивания/встряски |
| `sprite.py` | Кадры пиксельного спрайта и цветовые палитры |
| `bubble.py` | Речевые облачка и визуализация снов |
| `dialogs.py` | Окно чата и интерфейс настроек |
| `ai_client.py` | HTTP-клиент для OpenAI-совместимых API |
| `config.py` | Управление конфигурацией и загрузка `.env` |
| `i18n.py` | Интернационализация (поддержка языков) |
| `phrases.py` | Диалоги питомца, сны и системные промпты AI |
| `setup_local_model.ps1` | Вспомогательный скрипт для настройки локальной модели Ollama (Windows) |
| `run.sh` | Скрипт запуска для Linux |
| `build.bat` | Автоматизация сборки через PyInstaller (Windows) |

## Приватность

**Clawd не собирает никакой телеметрии или аналитики.** Смотрите [PRIVACY.md](PRIVACY.md) для полной политики конфиденциальности.

## Безопасность

- **Никогда не коммитьте** `config.json`, `.env`, API-ключи, загруженные модели или артефакты сборки
- **Отзывайте учётные данные**, если они были закоммичены или разглашены (даже случайно)
- `.env.bait` — это файл-приманка для обнаружения сканеров; приложение никогда его не читает
- **Сетевая активность** ограничена вашим настроенным API или только локальным сервером Ollama
- **Без слежения, без телеметрии, без аналитики**
