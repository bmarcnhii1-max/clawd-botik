# Clawd — Настільний AI-улюбленець

Чарівний піксельний улюбленець для вашого робочого столу Windows або Linux. Спостерігайте, як він гуляє, спить і бачить сни. Взаємодійте з ним через кліки та перетягування. Спілкуйтеся з ним через будь-який OpenAI-сумісний API або локальну модель Ollama.

## Можливості

- Прозорий піксельний улюбленець, що завжди поверх вікон, із плавною анімацією
- Повна підтримка взаємодії: перетягування, кидки, погладжування та дотики
- Симуляція фізики: гравітація, самостійна ходьба, сон і хмаринки снів
- Сім кольорових палітр і чотири розміри на вибір, зокрема кругла форма Амняма
- Багатомовний інтерфейс: англійська, російська, українська
- AI-чат з історією розмов
- Хмарний AI-режим: працює з будь-яким OpenAI-сумісним API
- Локальний AI-режим: приватна робота через Ollama (швидкі відповіді без розширеного мислення)
- Інтеграція з системним треєм і захист від повторного запуску
- Опціональний Windows-виконуваний файл (без автозапуску, портативний)

## Вимоги

- **ОС**: Windows 10/11 або Linux (рекомендовано X11; Wayland працює через XWayland)
- **Python**: 3.10 або новіше (перевірено до 3.14)
- **Ollama**: необов'язково, лише якщо хочете використовувати локальні AI-моделі

## Швидкий старт (Windows)

```powershell
# Створіть та активуйте віртуальне середовище
python -m venv .venv
.venv\Scripts\Activate.ps1

# Встановіть залежності
pip install -r requirements.txt

# Запустіть Clawd
python main.py
```

**Альтернатива:** Після встановлення залежностей просто запустіть:
```powershell
run.bat
```

## Швидкий старт (Linux)

X11 повністю протестовано; Wayland працює через XWayland (на GNOME може знадобитися розширення AppIndicator).

### Встановлення залежностей

```bash
sudo apt update
sudo apt install -y python3-venv python3-pip libgl1 libegl1 libxcb-cursor0 \
  libxkbcommon-x11-0 libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-render-util0
```

### Запуск Clawd

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
chmod +x run.sh
./run.sh
```

### Усунення проблем на Wayland

Якщо прозорість, позиціювання вікна або іконка трею поводяться дивно:
```bash
QT_QPA_PLATFORM=xcb ./run.sh
```

**Примітка:** `build.bat` і `setup_local_model.ps1` працюють лише на Windows. На Linux встановіть Ollama окремо через офіційний інсталятор; `config.py` та `.env` працюють однаково на всіх платформах.

## Налаштування AI

Clawd чудово працює без AI (він гулятиме, спатиме та бачитиме сни). Для чату потрібен або хмарний API, або локальна модель Ollama.

### Варіант 1: Хмарний API (OpenAI-сумісний)

**Через інтерфейс:**
1. Клікніть правою кнопкою на улюбленці → **AI settings…**
2. Введіть URL API, ключ API та назву моделі
3. Збережіть і починайте спілкування

**Через файл конфігурації:**
1. Скопіюйте `config.example.json` у `config.json`
2. Відредагуйте налаштування AI
3. Перезапустіть Clawd

(`config.json` ігнорується Git-ом)

### Варіант 2: Змінні середовища

Створіть або відредагуйте `.env`:

```dotenv
CLAWD_AI_BASE_URL=https://api.example.com/v1
CLAWD_AI_MODEL=model-name
CLAWD_AI_KEY=your-api-key
```

Змінні середовища мають вищий пріоритет за значення з `config.json`. (`.env` ігнорується Git-ом)

### Варіант 3: Локальна модель Ollama

**Автоматичне налаштування (Windows):**
```powershell
powershell -ExecutionPolicy Bypass -File .\setup_local_model.ps1
```
Скрипт завантажить Gemma 4 E2B (~3,1 ГБ) і налаштує її автоматично.

**Ручне налаштування (всі платформи):**
```bash
ollama pull gemma4:e2b
```
Потім встановіть `ai_local_model` у значення `gemma4:e2b` в `config.json` і виберіть **AI model → Local — Gemma 4 E2B** у меню трею.

## Керування

| Дія | Ефект |
|-----|-------|
| **Лівий клік** | Доторкнутися або погладити улюбленця |
| **Потрійний лівий клік** | Відкрити чат зі ШІ |
| **Перетягування** | Переміщати улюбленця по екрану |
| **Перетягнути + кинути** | Підкинути улюбленця, щоб він полетів |
| **Перетягнути + струсити** | Перемикати мови: англійська → російська → українська |
| **Правий клік** | Відкрити контекстне меню |
| **Подвійний клік по іконці в треї** | Перемкнути видимість улюбленця |

**Поведінка:** Улюбленець автоматично засинає після 3 хвилин бездіяльності та може показувати хмаринки снів під час сну.

## Побудова Windows-виконуваного файлу

### Повна побудова

```powershell
pip install -r requirements-dev.txt
build.bat
```

Результат: `dist\Clawd.exe` (самостійний виконуваний файл)

**Примітка:** Моделі, `config.json`, `.env` і артефакти побудови *не* пакуються всередину — тримайте їх у тій самій теці, що й виконуваний файл.

### Швидка побудова (для розробки)

```powershell
build.bat fast
```

Повторно використовує кеш PyInstaller і будує версію у теці (`dist\Clawd\Clawd.exe`) для швидших ітерацій.

## Структура проєкту

| Файл | Призначення |
|------|-------------|
| `main.py` | Точка входу, меню системного трею, захист від повторного запуску |
| `pet_window.py` | Поведінка улюбленця, анімації, фізика, обробка перетягування/струсу |
| `sprite.py` | Кадри піксельного спрайта та кольорові палітри |
| `bubble.py` | Мовні хмаринки та візуалізація снів |
| `dialogs.py` | Вікно чату та інтерфейс налаштувань |
| `ai_client.py` | HTTP-клієнт для OpenAI-сумісних API |
| `config.py` | Управління конфігурацією та завантаження `.env` |
| `i18n.py` | Інтернаціоналізація (підтримка мов) |
| `phrases.py` | Діалоги улюбленця, сни та системні промпти AI |
| `setup_local_model.ps1` | Допоміжний скрипт для налаштування локальної моделі Ollama (Windows) |
| `run.sh` | Скрипт запуску для Linux |
| `build.bat` | Автоматизація побудови через PyInstaller (Windows) |

## Приватність

**Clawd не збирає жодної телеметрії чи аналітики.** Дивіться [PRIVACY.md](PRIVACY.md) для повної політики приватності.

## Безпека

- **Ніколи не комітьте** `config.json`, `.env`, API-ключі, завантажені моделі або артефакти побудови
- **Відкликайте облікові дані**, якщо вони були закомічені або розголошені (навіть випадково)
- `.env.bait` — це файл-приманка для виявлення сканерів; застосунок ніколи його не читає
- **Мережева активність** обмежена вашим налаштованим API або лише локальним сервером Ollama
- **Без стеження, без телеметрії, без аналітики**
